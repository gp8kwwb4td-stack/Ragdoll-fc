# ⚽ Ragdoll FC

A 3D ragdoll football (soccer) game that runs in your browser — on your phone or computer. No install, just open `index.html`.

## Play it
- **Online:** turn on GitHub Pages for this repo (Settings → Pages → Deploy from branch → `main` / root). Your game will be at `https://<your-username>.github.io/<repo-name>/`
- **Offline:** download `index.html` and open it in a browser (it needs internet once to load the 3D engine).

## Features
- Walkable 3D **lobby** with pads: Join Red / Join Blue, Training, Hair Salon, How to Play, juggling spot + record board
- **5-a-side matches** with 4 levels: Easy, Normal, Hard, Pro
- Full **ragdoll physics** — slide tackles send players flying
- **Skills**: rainbow flick, step-overs, drag back, knock-on sprint, flick up
- **Bicycle kicks**, **headers**, aimed shots with power & height meter, lobs, passes, pokes, juggling
- **Celebrations**: SIUUU (with the shout!), knee slide, backflip, dance, airplane
- **TV-style goal replays** with slow motion
- Shirt numbers & names, 14 hairstyles, living stadium with crowd, flags, nets that ripple

## Controls
| Phone | Computer | Action |
|---|---|---|
| Left stick | WASD | Run |
| Drag right side | Mouse drag / Q E | Camera |
| KICK (hold, drag to aim) | Space (hold, move mouse to aim) | Shoot |
| LOB | F | Chip shot |
| PASS | Z / P | Pass to the teammate you steer toward |
| HEADER | H | Header |
| BICYCLE | B | Bicycle kick |
| SKILLS stick | 1–6 | Skill moves (up-then-down = rainbow flick) |
| JUGGLE | J | Juggle |
| SPRINT | Shift | Sprint |
| SLIDE | V | Slide tackle |
| POKE | R | Steal the ball |
| CALL / LOCK | C / X | Call for the ball / lock camera on ball |

Built with [three.js](https://threejs.org/).
